## 📌 About The Project

**Student Career AI** is a full-stack web application built to provide a centralized platform for managing student academic and career information.

The system supports multiple user roles including:

- 👨‍🎓 Students
- 👨‍🏫 Faculty
- 🛡️ Administrators

The application combines a modern Vite/React frontend with a Flask backend and MySQL database.

---

## ✨ Features

### 🔐 Authentication & Authorization

- Secure user login
- Role-based access
- Student, Faculty, and Admin accounts
- Password hashing
- Session/token-based authentication
- Protected backend routes

### 👨‍🎓 Student Management

- Student profiles
- Academic records
- Academic performance tracking
- Attendance information
- Skills management
- Project information
- Assessment records

### 👨‍🏫 Faculty

- Faculty authentication
- Student-related academic information
- Academic record management
- Assessment-related functionality

### 🛡️ Admin

- Administrative authentication
- User management
- Role-based system access
- Centralized student and academic data
